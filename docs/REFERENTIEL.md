# Référentiel

Les sources officielles sont importées, vérifiées, versionnées puis publiées. Une fiche cite la source, la version et la page. Sans référence vérifiable, elle reste un brouillon.

## MOHEBS

Les ressources MOHEBS sont rattachées à une langue nationale, un niveau et une étape de transfert (émergence L1, transition L1→L2, consolidation bilingue).
