# Installation

1. `npm install`
2. `cp .env.example .env.local`
3. Renseignez les clés Supabase.
4. Exécutez les migrations 001 à 012 puis seed.sql.
5. `npm run dev`
6. Ouvrez http://localhost:3000.

## Déploiement GitHub + Vercel

1. Créez un dépôt GitHub.
2. Poussez le contenu de ce dossier.
3. Connectez le dépôt à Vercel.
4. Ajoutez les variables d’environnement.
5. Déployez.

## MOHEBS

Le dossier MOHEBS est accessible dans la bibliothèque enseignant avec filtre par langue nationale et étape de transfert. Les administrateurs téléversent les ressources via Bibliothèque MEN > Dossier MOHEBS.
